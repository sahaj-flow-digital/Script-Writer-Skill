# Script Writer Skill

Claude Code skill for writing and editing Flow Digital's long-form "hero" video scripts, adapted per presenter.

- **New here?** Start with [`SETUP.md`](./SETUP.md) — installing the skill, SSH access, and how the auto-update/commit workflow works.
- **What the skill does:** [`SKILL.md`](./SKILL.md) — the arc, principles, and rules Claude follows when drafting or editing a script.
- **Presenter voices:** [`presenters/`](./presenters/) — one file per presenter (voice, output format). Loaded on top of `SKILL.md`.
